# Журнал изменений

Все заметные изменения приложения описываются здесь. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.3.0] - 2026-10-07

### Добавлено
- Вкладка «Оновлення графіка»: история изменений графика для выбранного
  города — какая черга, на какой день и что именно поменялось
  (например, «+ відключення 14:00–16:00»).
- Автоматическая проверка обновлений графика каждые 30 минут на сервере:
  изменения фиксируются в базе и сразу видны во вкладке. История хранится
  14 дней.

### Изменено
- Список при выборе города теперь содержит только населённые пункты —
  города, посёлки и сёла (справочник из 25 848 пунктов по Украине).
  Районы и громады убраны из выбора.
- Сёла с одинаковыми названиями различаются громадой:
  «Андріївка (Димерська громада)».
- Подвал главного экрана: «Дані з офіційних та неофіційних джерел» вместо
  упоминания конкретного сайта.
- Подпись автообновления: «Перевіряємо оновлення кожні 30 хв».

### Исправлено
- Из списка городов больше не выпадают служебные страницы «Графік Черга 1.1»
  до ввода названия города.

## [0.2.0] - 2026-10-07

### Добавлено
- Выбор области и города с поиском, выбор черги из доступных в графике.
- График на сегодня и завтра, три стиля отображения
  (минимальный / стандартный / расширенный).
- Уведомления о ближайших отключениях через Telegram-бота.

## [0.1.0] - 2026-10-06

### Добавлено
- Первый релиз: график отключений света по чергам, Киев через официальный
  API Yasno, остальные области через bezsvitla.
